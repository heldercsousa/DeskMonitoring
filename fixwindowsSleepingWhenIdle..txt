  Problem Solved

  Root Cause: Windows was entering sleep/USB suspend mode, which would kill the
  webcam power despite any motion detection needs. The system wasn't recovering
  automatically.

  The Fix

  Enhanced fix_power_motion.ps1 to apply three layers of power protection:

  1. Windows Power Plan Settings (via powercfg)

  - ✅ USB Selective Suspend → Disabled (both AC and DC)
  - ✅ Sleep → Never (both AC and DC)
  - ✅ Hibernate → Never (both AC and DC)
  - ✅ Display off → 10 min (AC) / 2 min (DC) — screen can sleep, system cannot

  2. Webcam Device-Level Power Management (NEW)

  - Programmatically disables Device Manager "Allow the computer to turn off
  this device to save power" setting
  - Prevents the webcam driver from sleeping even if Windows power plan allows
  it
  - Uses WMI to detect webcam + registry to set PowerDownLevel=0

  3. Failsafe Monitoring (Already in place)

  - yawcam_monitor_v4.ps1 checks every 60 seconds for recent recordings
  - If no recording in 15+ minutes, automatically restarts Yawcam with camera
  reset
  - 10-minute cooldown between restart attempts to avoid thrashing
